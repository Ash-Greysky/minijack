Blackjack in Bash!

Learning project.

how to run:
bash jack.sh

how to play;
* Get as close as you can to 21 without going over!
* Dealer stands on soft 17
* Blackjack pays out 3:2
* Natural Blackjack pays out double
* Tie is a 1:1 refund, even on blackjacks
* Win by reaching integer overflow.

Have fun and don't gamble real money :)
